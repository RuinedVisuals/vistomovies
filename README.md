# Athens Showtimes — scraper Αθηνοράματος

Python 3.11+, SQLite και τοπικό JSON API. Δεν χρειάζεται paid API, λογαριασμός ή API key. Το React frontend μπορεί να συνδεθεί στο API. Το frontend δεν περιλαμβάνεται σε αυτό το πακέτο.

## Εκκίνηση στα Windows / PowerShell

Αποσυμπίεσε το ZIP και μπες στον φάκελο `athens-showtimes`:

```powershell
py -m pip install -r requirements.txt
py -m showtimes scrape --week-start 2026-10-01
py -m showtimes serve
```

Το `--week-start` είναι η Πέμπτη του προγράμματος που έχεις επιβεβαιώσει. Το παραπάνω αφορά **1–7 Οκτωβρίου 2026**. Μην το επαναχρησιμοποιήσεις για επόμενες εβδομάδες.

Η σελίδα δίνει ημέρες εβδομάδας, όχι σαφή ημερομηνία ισχύος. Γι' αυτό απαιτείται ρητή ημερομηνία: δεν θεωρούμε ότι ένα παλιό/μη ενημερωμένο πρόγραμμα αφορά αυτόματα την τρέχουσα εβδομάδα. Πριν από κάθε εβδομαδιαία αλλαγή, επιβεβαίωσε το πρόγραμμα. Δεν έχει ενεργοποιηθεί αυτόματο cron.

Άνοιξε:
- http://127.0.0.1:8787/showtimes/today
- http://127.0.0.1:8787/showtimes?date=2026-10-05
- http://127.0.0.1:8787/health

Linux/macOS: χρησιμοποίησε `python3` αντί `py`.

## Τι περιλαμβάνει

- Μία λήψη της δημόσιας HTML σελίδας https://www.athinorama.gr/cinema/guide/all/cinemas/ ανά εκτέλεση, μετά από έλεγχο robots.txt.
- Ανάγνωση κινηματογράφου, αίθουσας, τίτλου, ημερών, πολλαπλών ωρών και συνδέσμου πηγής.
- Μετατροπή των ελληνικών συνδυασμών ημερών σε ημερομηνίες.
- SQLite, σταθερά IDs, αποφυγή διπλοεγγραφών και συναλλακτική αντικατάσταση του προηγούμενου προγράμματος.
- Εξαγωγή JSON και τοπικό API, με κατάσταση πηγής / τελευταίο επιτυχημένο έλεγχο.
- Αναφορά `data/parse-report.json`: όλες οι αίθουσες που εμφανίζονται, όσες έχουν ωράριο και μη αναγνωρισμένα schedules.
- Αν προκύψει άγνωστη σύνταξη ή σφάλμα HTTP, η εισαγωγή αποτυγχάνει και διατηρεί τα προηγούμενα δεδομένα. Ο καταναλωτής πρέπει να ελέγχει `sources[].error` / `lastSuccessAt`.

## Έλεγχος 5 Οκτωβρίου 2026

Από το HTML που κατέβηκε πραγματικά: **61 καταχωρίσεις κινηματογράφων, 59 με αναγνώσιμα ωράρια, 68 διαφορετικοί σύνδεσμοι ταινιών, 2.081 εγγραφές προβολών**, μηδέν μη αναγνωρισμένες γραμμές προγράμματος. Άστορ και Cinobo Μασκώτ εμφανίζονται χωρίς ωράρια στη συγκεκριμένη σελίδα. Άρα δεν ισχυριζόμαστε πλήρη κάλυψη Αθήνας.

Το `data/showtimes.json` και η SQLite είναι στιγμιότυπο αυτής της λήψης, όχι εγγύηση μελλοντικής λειτουργίας ή live ενημέρωση. Οι ημερομηνίες βασίζονται στη δηλωμένη εβδομάδα 1–7/10/2026. Έξι unit tests καλύπτουν εύρη ημερών, πολλαπλές ώρες, σημειώσεις, απόρριψη άγνωστων δεδομένων και διατήρηση βάσης σε αποτυχία.

## Λεπτομέρειες δεδομένων

`rawSchedule` κρατά ακριβώς το ωράριο και τις σημειώσεις (μεταγλώττιση, Dolby, προσφορές). Δεν συλλέγονται κριτικές, περιλήψεις ή αφίσες. Οι σημειώσεις παραμένουν στο raw κείμενο, όχι ως επιβεβαιωμένο format κάθε προβολής.

Ώρες πριν από 06:00 ερμηνεύονται ως το επόμενο ημερολογιακό πρωί της ημέρας προγράμματος: `date` η ημερομηνία προβολής, `programmeDate` η αρχική ημέρα, `afterMidnight: true`. Αυτή η σύμβαση χρειάζεται διασταύρωση με το σινεμά πριν χρησιμοποιηθεί για ειδοποιήσεις/κρατήσεις. Ζώνη ώρας: Europe/Athens.

Το `bookingUrl` είναι `null`: δεν εφευρίσκονται σύνδεσμοι αγοράς. Χρησιμοποίησε `sourceUrl` ως «Δες την πηγή». `movieSourceUrl` επιτρέπει αργότερα αντιστοίχιση με TMDB. Διαφορετικές κόπιες/ονόματα δεν συγχωνεύονται αυθαίρετα.

## Χρήσιμες εντολές

```powershell
py -m showtimes export
py -m showtimes export --date 2026-10-05 --out data/today.json
py -m showtimes status
py -m unittest discover -s tests -v
py -m showtimes scrape --html saved-page.html --week-start 2026-10-01
```

Για React/Vite, πρόσθεσε στο `server.proxy` του vite.config.ts:

```ts
'/api': { target: 'http://127.0.0.1:8787', rewrite: path => path.replace(/^\/api/, '') }
```

και κάλεσε `fetch('/api/showtimes/today')`. Το API ακούει μόνο σε localhost. Για production χρειάζεται κανονικό API server/reverse proxy, scheduling και monitoring· ο ενσωματωμένος HTTP server προορίζεται για ανάπτυξη.

## Συντήρηση / χρήση πηγής

Το robots.txt ελέγχεται ανά εκτέλεση, χωρίς παράκαμψη αποκλεισμών, CAPTCHA, login ή ουρών. Δεν αποτελεί άδεια αναδημοσίευσης. Πριν από δημόσια χρήση χρειάζεται έλεγχος των όρων/συμφωνία χρήσης δεδομένων. Απέφυγε συχνές λήψεις· 1–2 ημερησίως αρκούν για αρχική δοκιμή, εφόσον επιτρέπονται.

Αν αλλάξει το HTML ή η σύνταξη ωραρίων, διόρθωσε `showtimes/athinorama.py`. Τα `parsers.py` / `discover` είναι προαιρετικό αρχικό εργαλείο εντοπισμού links More και parser Μικρόκοσμου, δεν απαιτούνται από τον scraper Αθηνοράματος και δεν ισχυρίζονται live κάλυψη άλλων πηγών.
